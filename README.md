# Prospect writing

An Exo skill for preparing emails and public comments from a current prospect plan. Drafts enter Operator for review. This skill does not send or schedule messages.

Install from the Audienti marketplace or copy `skills/prospect-writing` into an agent skills directory.

Host workflow names in the skill describe integration contracts. Installing the skill
does not create those APIs, deploy Exora, schedule jobs or authorize outreach.

Claude Code installation:

```sh
claude plugin install prospect-writing --marketplace audienti/plugins
```

Codex installation (after adding the Audienti marketplace):

```sh
codex plugin add prospect-writing@audienti
```
